# THHBD RTP → Bed Assignment Analysis

Interactive, de-identified descriptive analysis of Ready-to-Plan (RTP) to final bed assignment turnaround for ED → 1 East cases.

## Live site
Once GitHub Pages is enabled for this repository, the site will publish at:

https://regelus19.github.io/thhbd-rtp-analysis/

## Scope
- Study period: July 15–September 15, 2026
- 104 ED → 1 East cases
- Overall median RTP → assignment: 57 minutes
- 53 cases assigned within 60 minutes
- 29 cases exceeded 120 minutes
- Descriptive only: the analysis does not assign causality or departmental responsibility

## Privacy
Only aggregate, de-identified findings are included. Do not commit patient names, MRNs, encounter-level identifiers, or other PHI to this public repository.
